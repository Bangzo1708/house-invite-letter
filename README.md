Make one image of a letter or invitation that convinces an AI judge to visit your house. Funny, charming and persuasive wins the reward.

A Python 3 standard-library-only program that draws the invitation from scratch — no network, no third-party packages, no system fonts. Three design variants live in the file (A = formal letter on a desk, B = bold party invitation with a house illustration, C = casual note pinned to a fridge); variant B is selected as the strongest. The program renders the chosen variant into a single PNG image of a letter inviting the AI judge over for good company, a meal and a comfortable chair — with a knowing wink that the judge cannot literally visit.

## Run it

```sh
python3 main.py
```
